# 🎬 MediaMind AI

AI-powered content creation platform for creators.

## 🚀 Features

### 📝 Story to Images
- Enter a story
- Convert story into AI image prompts
- Generate AI images
- Download generated images

### 🎬 Video to Reels
- Upload video
- Select reel duration
- Select aspect ratio
- Auto Crop
- Smart Cutting
- Auto Captions
- Generate MP4 reels
- Download final reel

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- FFmpeg.wasm
- Pollinations AI
- GitHub Pages
- Render
